你好，我是**张三**，一名前端工程师，目前主要做 Web 性能和前端基础设施相关的工作。

这个博客用来记录三类东西：

- **技术笔记** —— 那些查了半天资料才解决的问题，写下来免得下次再查一遍
- **工程实践** —— 关于架构、协作和工具选择的思考，通常来自踩过的坑
- **随笔** —— 和代码无关，但和思考方式有关的东西

## 这个站点

它是一个纯静态博客，没有数据库，也没有需要长期运行的后端。每次写完文章推送到仓库，CI 会自动构建并部署。

技术上的选择很克制：

- [Astro](https://astro.build) 负责构建，默认不向浏览器发送任何框架代码
- 样式用 Tailwind CSS 手写，没有使用现成的排版插件
- 搜索由 [Pagefind](https://pagefind.app) 在构建时生成索引
- 评论托管在 GitHub Discussions 上
- 字体全部使用系统自带，不加载任何外部字体

源码是开源的，如果你想用它搭自己的博客，直接 fork 然后改 `src/site.config.ts` 就可以。

## 联系

有问题或者想聊聊，可以通过页脚的任意方式找到我。邮件通常回得最快。

如果你在文章里发现了错误，欢迎直接提 Issue —— 我会很感激。
