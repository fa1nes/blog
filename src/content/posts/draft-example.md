如果你是在 `npm run dev` 里读到这篇，说明草稿功能正常工作。执行 `npm run build` 之后它会被完全排除：不生成页面、不进列表、不进归档、不进 RSS、也不进搜索索引。

想发布的时候，把 frontmatter 里的 `draft: true` 删掉或改成 `false` 就行。

## 两种藏起稿子的方式

除了 `draft` 字段，还可以给文件名加下划线前缀：

| 方式 | 开发时 | 构建后 | 适合 |
| --- | :---: | :---: | --- |
| `draft: true` | 可见 | 排除 | 正在写、想随时预览的稿子 |
| 文件名以 `_` 开头 | 不可见 | 排除 | 素材、片段、暂时不想加载的东西 |

下划线前缀是在内容集合的 glob 规则里过滤掉的（见 `src/content.config.ts`），那类文件连解析都不会发生，所以 frontmatter 写错了也不会报错。

读完可以直接删掉这个文件。
